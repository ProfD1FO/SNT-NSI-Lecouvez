# Chapitre 3 - Les séquences

En informatique, une **séquence** est une collection ordonnée d'éléments, accessibles selon leur position.

Jusqu'à présent, nos variables contenaient principalement une seule valeur : un entier, un booléen, un flottant… Cela devient rapidement limitant lorsque l'on souhaite manipuler plusieurs valeurs à la fois.

Pourtant, nous avons déjà manipulé une séquence sans le savoir : une chaîne de caractères est elle-même constituée d'une succession de caractères, accessibles grâce à leur position.

Dans ce chapitre, nous allons généraliser cette notion et découvrir d'autres types de séquences, notamment les **listes** et les **tuples**.


## Au programme

- Manipulation et parcours de premières séquences avec des chaînes de caractères

- Découverte des listes Python et manipulations

- Découvertes des tuples Python et manipulations
