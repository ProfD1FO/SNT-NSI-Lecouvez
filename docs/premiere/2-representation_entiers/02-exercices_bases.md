# Exercices 1 : Les bases de nombres

## Exercice 1 - Décomposer en décimal

### Q1 - Pour chacun des nombres entiers suivants : donnez sa décomposition en **puissance de 10** :

- 31
- 613
- 3
- 1726
- 19293

### Q2 - Maintenant, pour chacune des décompositions ci-dessous, donner sa valeur en écriture décimale

- $1\times10^2 + 0\times10^1 + 8\times10^0$
- $8\times10^3 + 9\times10^2 + 1\times10^1 + 0\times10^0$
- $4\times10^1 + 8\times10^0$
- $1\times10^4 + 1\times10^3 + 9\times10^2 + 5\times10^1 + 7\times10^0$

## Exercice 3 - Nombres possibles

Nous l'avons vu, une base possède un nombre limité de symbole qui correspond à chaque fois à la puissance utilisée. 
Indiquez donc si les écritures ci-dessous sont valides ou non:

- $91_7$
- $2013_2$
- $10_2$
- $FFFF_{16}$
- $G12_{16}$
- $12{8}$
